WordPress plugin for smart image optimization. Auto-converts to WebP, includes smart lazy loading, and generates missing alt text for better SEO.

== Description ==

**GioCompress** is the lightweight yet powerful WordPress plugin designed to automatically optimize and convert your images into modern, web-friendly formats. It helps your website load faster without compromising visual quality, boosting your SEO scores and user experience.

GioCompress offers both a **Free version** with essential optimization features and a **PRO version** for advanced control and maximum performance.

---

## 🚀 Key Features (Free Version)

With **GioCompress (Free version)**, your site gets an immediate boost in speed and better SEO:

* **Automatic Compression on Upload:** Every image you upload is instantly optimized for the web.
* **Automatic WebP Conversion:** Your images are automatically converted to the WebP format, ensuring superior performance and exceptional visual quality.
* **Optimization of Scaled Images:** Even thumbnails and all various image sizes generated by WordPress are optimized.
* **Delete Original File:** By default, we keep only the optimized version to maximize disk space savings on your server.
* **Optimize Existing Images (5/day):** Already have a site full of images? Start optimizing your existing galleries right away, with a limit of 5 images per day.
* **Smart Lazy Loading (SEO):** Your images load only when they are visible to the user, significantly improving page speed and SEO ranking. It works on all images on your site, wherever they are inserted.
* **Generate Missing Alt Text (SEO):** Unique in its class! The plugin automatically detects and generates the **ALT attribute** for images that are missing it or have an empty ALT (`alt=""`), drastically improving your SEO and site accessibility.

## ⚙️ How It Works

Once activated, GioCompress works in the background completely automatically. It intercepts images uploaded to your site and processes them, optimizing and converting them into modern formats like WebP or AVIF. The optimized versions are then served on your site, guaranteeing quick loads and reduced bandwidth consumption. It's a one-time setup, and then it does all the work for you!

== Installation ==

1.  Upload the `gio-compress` folder to the `/wp-content/plugins/` directory of your WordPress site.
2.  Activate the **GioCompress** plugin through the 'Plugins' menu in your WordPress dashboard.
3.  Access the GioCompress settings page to configure your preferences (found under `Settings -> GioCompress`).
4.  Your new images will automatically be optimized on upload! To optimize existing images, use the "Optimize Existing Images" feature from the plugin settings.

== Frequently Asked Questions ==

= Does this plugin replace my original files? =
By default, in the free version, GioCompress replaces original JPG/PNG files with optimized WebP versions. In the PRO version, you have the option to choose whether to keep or delete the original files.

= How does the automatic Alt Text generation work? =
GioCompress analyzes images that either lack an ALT attribute or have an empty one (`alt=""`) and attempts to automatically generate it based on information such as the file name, the image title in the media library, the caption, or the title of the post the image is associated with. This improves the accessibility and SEO of your images.

= Does the plugin use external cloud services for optimization? =
No, GioCompress is a completely server-side plugin. All optimizations happen directly on your WordPress server. This ensures greater control over your data and no reliance on external services.

= Is the plugin compatible with all themes and page builders? =
GioCompress is designed to work with most themes and page builders, including Elementor, Divi, and the Gutenberg block editor, thanks to its Output Buffering optimization approach. If you encounter any issues, please report them via the bug report form or email support (for PRO users).

= How can I access the Pro version? =
The PRO version of GioCompress can be purchased and downloaded from our official website (link to be provided soon). Once you have your PRO license key, you can activate it directly within the plugin's settings to unlock all advanced features.

= 1.4.0 =
* Fixed: optimizing existing images no longer breaks images already inserted in posts. Old JPG/PNG URLs are replaced in post content, excerpts and post meta (including page builder JSON), and requests for the old files are redirected (301) to the converted file. The redirect also repairs images converted by previous versions.
* Fixed: uploading an image with the same name as an existing one (e.g. a second `photo.jpg`) no longer overwrites the previously converted `photo.webp`.
* Fixed: photos taken with smartphones are no longer rotated after conversion (EXIF orientation is applied). The color profile is kept.
* Fixed: image sizes sharing the same file (e.g. two 150x150 sizes) are all converted, with no broken thumbnails.
* Fixed: attachment metadata, dimensions and MIME type are updated correctly after converting existing images.
* Fixed: the free daily limit allowed 6 optimizations instead of 5 and counted images converted on upload.
* Fixed: "Optimize All" counted failed images as optimized and could stall on network errors; the result notice was never shown.
* Fixed: the renewal button pointed to a development URL.
* Security: removed an unprotected bulk optimization endpoint; AJAX requests now require a nonce and use POST.
* Improved: lazy loading skips the first images of the page and images marked with fetchpriority="high", to avoid slowing down the LCP.
* Improved: missing alt text lookup is faster and recognizes resized image URLs.
* Improved: the preserved original is deleted together with its attachment.
* Changed: bundled translation files removed; translations are provided by translate.wordpress.org (and by GioCompress Pro).
* Changed: quality, resizing and original preservation are applied only with an active Pro license, as described in the feature comparison.
